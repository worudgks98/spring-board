# Spring Boot 게시판 프로젝트

## 프로젝트 소개

Spring Boot와 JPA를 활용한 게시판 프로젝트입니다.

회원가입 및 로그인 기능을 구현하였으며, 로그인한 사용자만 게시글 작성이 가능합니다.

또한 게시글 작성자만 수정 및 삭제할 수 있으며, 게시글에 댓글을 작성할 수 있습니다.

---

## 개발 환경

* Java 17
* Spring Boot 3
* Spring Data JPA
* Thymeleaf
* MySQL
* Gradle

---

## 주요 기능

### 회원 기능

#### 회원가입

* 이메일
* 이름
* 비밀번호 입력
* 회원 정보 DB 저장

#### 로그인

* 이메일 + 비밀번호 검증
* 로그인 성공 시 Session 생성
* Session에 로그인 이메일 저장

#### 로그아웃

* Session 제거
* 게시글 목록 페이지로 이동

---

### 게시글 기능

#### 게시글 작성

* 로그인한 사용자만 가능
* 작성자는 로그인 이메일 자동 입력
* 게시글 저장 후 목록 이동

#### 게시글 목록 조회

* 전체 게시글 조회
* 게시글 번호
* 제목
* 작성자
* 작성일
* 조회수 출력

#### 게시글 상세조회

* 게시글 내용 확인
* 조회수 증가

#### 게시글 수정

* 게시글 작성자만 가능
* 본인 글만 수정 가능

#### 게시글 삭제

* 게시글 작성자만 가능
* 본인 글만 삭제 가능

---

### 댓글 기능

#### 댓글 작성

* 로그인한 사용자만 가능
* 작성자는 로그인 이메일 자동 입력
* 게시글 상세 페이지에서 작성 가능

#### 댓글 조회

* 게시글별 댓글 목록 조회
* 최신 댓글이 위에 표시

#### 댓글 정보

* 댓글 번호
* 댓글 작성자
* 댓글 내용

---

## 권한 처리

### 비회원

가능

* 게시글 목록 조회
* 게시글 상세조회

불가능

* 게시글 작성
* 댓글 작성
* 게시글 수정
* 게시글 삭제

---

### 로그인 회원

가능

* 게시글 작성
* 댓글 작성

본인 게시글만 가능

* 게시글 수정
* 게시글 삭제

## 데이터베이스 테이블

### member_table

| 컬럼명             | 설명   |
| --------------- | ---- |
| id              | 회원번호 |
| member_email    | 이메일  |
| member_name     | 이름   |
| member_password | 비밀번호 |

---

### board_table_2025

| 컬럼명            | 설명    |
| -------------- | ----- |
| id             | 게시글번호 |
| board_title    | 제목    |
| board_writer   | 작성자   |
| board_contents | 내용    |
| board_hits     | 조회수   |

---

### comment_table

| 컬럼명              | 설명        |
| ---------------- | --------- |
| id               | 댓글번호      |
| comment_writer   | 작성자       |
| comment_contents | 댓글내용      |
| board_id         | 게시글번호(FK) |
